## How this report is bound, and why each command sits on its own line

The harness claim extractor (`tools/ai-run.php:extractClaims`) binds a command only when the command is
the **whole line** (optionally prefixed `$ ` or `> `) and it matches `COMMAND_ALLOWLIST`. A `COMMAND:`
label line is not itself parsed as a command. Revision 1 blocked because its only extractable line was
`git diff --check           PASS` — a status word inside the command, which is not allowlisted.

This report puts the exact command on its own line immediately after the `COMMAND:` label, so the
extractor binds it; label plus command are one declaration and the command is verbatim and pasteable.
`COMMAND: …` lines in the shown-evidence sections are deliberately non-binding (not allowlisted), so the
verifier can neither execute them nor mistake them for claims. This is a format adaptation, not a
relaxation: every command below is copied verbatim from what was actually run.
